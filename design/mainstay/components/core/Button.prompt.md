The system's primary action. Every conversion path ends in one.

```jsx
<Button size="lg" iconRight="arrow-right">Get a free quote</Button>
<Button variant="outline" iconLeft="phone">Call now</Button>
```

One primary per view. `secondary` (ink) is for the second-most-important action on light surfaces; `outline` pairs with a primary in hero rows; `ghost` for toolbar-level actions.
