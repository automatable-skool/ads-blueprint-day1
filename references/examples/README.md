# Examples

Finished files from a demo build for ABC Company, a fictional Toronto plumbing business.
These are the quality bar for what each command should produce.
Next: open the example that matches the command you are about to run.

## What each file shows

**business-example.md and proof-example.md** - the filled-in context files. This is what `/context-layer` produces.

**keyword-list-example.md** - ONE file: the account structure at the top (what `/keywords stag` writes) and the service keywords with volume below it (what `/keywords` writes).

**ad-library-example.md** - headline and description pools, tagged by angle and scored. This is what `/write-ads` produces.

**competitor-ads-example.md** - the competitor claim list plus the scored swipe file. This is what `/write-ads scout` produces.

**landing-page-example.html** - a finished converting landing page. This is what `/landing-page` produces.

## Rule

Never copy an example claim into a member's real ads. Every claim has to come from their own proof.md.

When a member asks what something should look like, show them the matching example above.
